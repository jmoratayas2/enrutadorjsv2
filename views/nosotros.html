Nosotros

Aprender construyendo

NovaWeb es un proyecto académico creado para comprender el funcionamiento interno de una SPA y la responsabilidad de un Router antes de utilizar frameworks modernos.

Nuestra misión

Comprender cómo JavaScript controla la navegación y actualiza únicamente el área de contenido.

Nuestra visión

Construir una base sólida para entender posteriormente routers de Angular, React o Vue.

Nuestros valores

Orden, claridad, buenas prácticas, reutilización y aprendizaje mediante ejemplos funcionales.

Idea principal:

El archivo index.html permanece cargado mientras JavaScript sustituye el contenido de #app por la vista solicitada.
